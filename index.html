02 / Installation

Prêt en quelques étapes.

Télécharge les fichiers

Récupère Peanut-GB au format .nwa et un jeu au format .gb.

Connecte la NumWorks

Utilise un câble USB permettant le transfert de données.

Ouvre le site NumWorks

Rendez-vous sur my.numworks.com/apps avec Chrome ou Edge.

Installe l'émulateur

Sélectionne le fichier .nwa, puis le jeu .gb dans « external data ». Clique sur Install et sélectionne la calculatrice.

⚠️ Un seul jeu à la fois

Chaque installation de Peanut-GB utilise un seul fichier .gb comme données externes.

Tu peux installer Pokémon Rouge, Pokémon Bleu ou Flappy Boy, mais pas plusieurs jeux simultanément dans la même application.

Pour changer de jeu, réinstalle Peanut-GB en sélectionnant une autre ROM. Pense à sauvegarder avant de remplacer le jeu.

Si l'installation échoue, vérifie le modèle de ta calculatrice, la version du système et la compatibilité des applications externes.

Consulte aussi la documentation Peanut-GB .

04 / Progression

Sauvegarde en deux temps.

Sauvegarder dans le jeu ne suffit pas toujours à conserver les données après la fermeture.

01

Dans Pokémon

Ouvre le menu avec ⌫ (Start), sélectionne SAUVER et valide avec Retour (A).

02

Dans Peanut-GB

Appuie sur Boîte à outils pour écrire la sauvegarde, ou sur 0 pour sauvegarder et quitter.

✓ Conseil : sauvegarde, quitte avec 0, relance l'application et vérifie que ta progression a été conservée.
À savoir

Et le mode examen ?

Les applications externes peuvent ne pas être autorisées pendant les examens. Vérifie le règlement applicable et retire les applications concernées si nécessaire.
