Game Boy sur NumWorks

Comment installer l'émulateur Peanut-GB, jouer et sauvegarder sa partie.

À savoir : ce guide ne fournit aucune ROM. Utilise uniquement un fichier .gb que tu as le droit d'avoir (dump de ta propre cartouche, ou un jeu libre comme Flappy Boy). Les apps externes peuvent aussi ne pas être acceptées pendant un examen : vérifie le règlement avant une épreuve.

0. Les deux fichiers à télécharger

L'émulateur (fichier .nwa, version 1.2.3) :
Télécharger peanutgb-1.2.3.nwa

Un jeu de test (Flappy Boy, fichier .gb, fourni avec l'émulateur) :
Télécharger flappyboy.gb

Pour un autre jeu, il te faut ta propre ROM .gb (dump de ta cartouche). Elle n'est pas fournie ici. Les liens pointent vers les sites d'origine, rien n'est hébergé sur cette page.

1. Installer l'émulateur

  1. Télécharge les deux fichiers ci-dessus (ou une version plus récente de Peanut-GB sur nwagyu.org).
  2. Branche la calculatrice en USB avec un câble de données.
  3. Ouvre my.numworks.com/apps avec Chrome ou Edge.
  4. Sélectionne le fichier .nwa, puis ta ROM .gb dans le champ « external data ».
  5. Clique sur Install et choisis NumWorks dans la fenêtre USB.

Utilise la version récente du site de l'auteur : l'ancienne version de la page GitHub Releases (1.0.0, 2022) affiche un carré noir autour des sprites dans les jeux Pokémon.

4. Sauvegarder sa partie

Il y a deux étapes, dans cet ordre :

  1. Dans le jeu : ouvre le menu avec ⌫ (Start), choisis SAUVER, valide avec Retour (A).
  2. Sur la calculatrice : appuie sur Boîte à outils pour écrire la sauvegarde, ou sur 0 pour écrire la sauvegarde et quitter.

Si tu quittes sans passer par là, tu peux perdre ta progression. Teste une fois : sauvegarde, quitte avec 0, relance l'app et vérifie que ta partie est là.

Mode examen

Le mode examen officiel se règle dans Paramètres → Mode examen. Les apps externes (émulateur, jeux) peuvent rendre la calculatrice non conforme : demande à ton établissement et supprime-les avant l'épreuve si besoin.
